CLASSY STORE PRO — FINAL BUILD
================================

هذا إصدار مستقل جديد. ارفع محتويات هذا المجلد كمشروع جديد، ولا تحتاج إلى تعديل ملفات مشروعك القديم.

1) إعداد Supabase
-----------------
- أنشئ مشروع Supabase جديداً.
- افتح SQL Editor وشغّل ملف SUPABASE_SETUP.sql كاملاً مرة واحدة.
- من Authentication > Users أنشئ حساب المدير.
- امنح الحساب app_metadata.role = admin من واجهة موثوقة/لوحة الإدارة لدى Supabase (لا تستخدم user_metadata ولا تضع service_role في المتصفح).
- لا تنشر لوحة الإدارة قبل ضبط دور المدير.

2) ربط الواجهة
--------------
- افتح config.js.
- ضع Project URL في SUPABASE_URL.
- ضع Publishable key أو anon key في SUPABASE_ANON_KEY.
- ضع رقم واتساب بصيغة دولية أرقام فقط في WHATSAPP_NUMBER، مثال: 9665XXXXXXXX.
- لا تضع service_role أو أي Secret key في config.js.

3) النشر
--------
- ارفع جميع الملفات والمجلدات كما هي إلى استضافة Static Hosting تدعم HTTPS.
- الصفحة الرئيسية: index.html
- لوحة الإدارة: admin.html
- لا تحذف assets أو ملفات manifest وsw.

الموجود في هذا الإصدار
----------------------
- متجر عربي RTL متجاوب، تصنيفات رئيسية وفرعية، بحث وفلاتر، ترتيب سعر.
- منتجات مع معرض صور، اختيار مقاس/لون، مفضلة محلية وسلة محلية.
- بانرات بمدة عرض قابلة للضبط، ريلز فيديو، Shop the Look.
- لوحة إدارة للمنتجات والأقسام والبانرات والريلز والإطلالات والطلبات.
- ضغط صور إلى WebP ورفع فيديو MP4/WebM إلى Supabase Storage.
- استيراد منتجات CSV.
- تسجيل الطلب من خلال RPC آمن يحسب السعر من قاعدة البيانات ويتحقق من المخزون ويخصم الكمية داخل معاملة واحدة.
- إدارة الطلبات تتطلب دور admin.

حدود يجب معرفتها
----------------
- لا توجد بوابة دفع إلكتروني مدمجة؛ تأكيد الطلب يتم عبر واتساب.
- المفضلة والسلة محفوظتان على الجهاز نفسه (localStorage)، وليستا حساب عميل متزامناً بين الأجهزة.
- المخزون الحالي على مستوى المنتج، وليس لكل تركيبة مقاس/لون.
- التوصيات قواعد بسيطة حسب الخصم والمخزون وليست ذكاءً اصطناعياً.
- لا توجد مزامنة مع شركات الشحن أو نظام محاسبي.
- ميزة newsletter لا تعرض نموذج اشتراك فعلياً في الواجهة الحالية.
- عند عدم إعداد Supabase يعمل المتجر ببيانات معاينة فقط؛ لن تعمل الإدارة أو حفظ الطلبات.

الأمان
-----
- مفتاح Supabase المسموح للواجهة فقط هو Publishable/anon key.
- لا تضع service_role key في ملفات الموقع أو ترسله لأي شخص.
- صلاحيات الإدارة تعتمد على app_metadata.role = admin وسياسات RLS.
- RPC checkout لا يقبل السعر من المتصفح؛ يستخرج السعر والاسم من جدول المنتجات.

فحص قبل الإطلاق
---------------
- جرّب تسجيل الدخول كمدير.
- أضف منتجاً تجريبياً وصورة WebP.
- أضف بانراً وريل فيديو وإطلالة.
- نفّذ طلباً بكمية متاحة ثم جرّب كمية أكبر من المخزون.
- تحقق من أن الطلب يظهر في لوحة الإدارة وأن المخزون انخفض.
- اختبر المتجر على هاتف Android وعلى شاشة كمبيوتر.
